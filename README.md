# Customer Intelligence / Segmentation Module

This module performs RFM Analysis and K-Means Clustering on the Olist 
e-commerce dataset to segment customers into: New, Regular, High-Value, 
and At-Risk categories.

## Files
- Customer_Segmentation_Notebook.ipynb — full analysis code
- Final_Customer_Segmentation.csv — final output with customer segments

## How it works
1. Data cleaning and preprocessing
2. RFM (Recency, Frequency, Monetary) analysis
3. K-Means clustering
4. Customer categorization
